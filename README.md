# 🛒 Tienda Tecnológica SENATI - CFP Huaraz

Plataforma web de catálogo e-commerce desarrollada para la comunidad educativa y profesional de **SENATI CFP Huaraz**. Ofrece una experiencia interactiva moderna para explorar y adquirir equipos de computación, periféricos, componentes de hardware, soluciones de red y software especializado.

![SENATI CFP Huaraz](/public/images/senati_campus_huaraz.jpg)

---

## ✨ Características Principales

* ⚡ **Arquitectura Moderna**: Desarrollado con **React 19** y **Vite 8** para tiempos de carga ultrarrápidos y HMR instantáneo.
* 🔍 **Búsqueda y Filtros en Tiempo Real**: Búsqueda dinámica integrada en el catálogo, filtros facetados por categoría, marcas, rangos de precio interactivos y estado de stock.
* 📱 **Diseño 100% Responsivo y Fluido**: Grilla adaptable que reordena automáticamente los productos y paneles laterales en laptops, tablets y móviles sin pérdida de contenido.
* 🛍️ **Gestión de Carrito de Compras**: Carrito deslizable (*Drawer*) con control dinámico de cantidades, cálculo de totales y persistencia de items.
* 🎨 **Estética Visual Premium**: Paleta de colores institucional SENATI (Navy, Cyan y Cobalt), microinteracciones sutiles, efectos Neón y tipografías optimizadas (*Outfit*, *Inter*, *Caveat*).
* 🧊 **Preparado para 3D & WebGL**: Integración lista con **Three.js**, `@react-three/fiber` y `@react-three/drei` para visualizaciones interactivas de productos.
* 🌐 **Estándares Google Modern Web**: Buenas prácticas de Core Web Vitals (INP, LCP, CLS), accesibilidad web y semántica HTML5.

---

## 🛠️ Stack Tecnológico

* **Frontend**: React 19, Vanilla CSS3 (Custom Properties & Glassmorphism)
* **Build Tool**: Vite 8
* **Gráficos 3D & Efectos**: Three.js, React Three Fiber, Canvas Confetti
* **Iconografía**: Lucide React / SVG optimizados
* **Linter**: Oxlint

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/ShadowNeural666AI/SENATI-CATALOGO-HUARAZ.git
   cd SENATI-CATALOGO-HUARAZ
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar en modo desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
